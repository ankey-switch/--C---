# A股双均线策略量化回测项目

一个基于 **akshare + pandas + matplotlib** 的模块化 A 股日频量化回测项目，内置经典**双均线（金叉/死叉）策略**，严格避免未来函数（信号 T 日收盘产生，T+1 开盘执行），并计入手续费与滑点。

## 项目结构

```
quant_backtest/
├── main.py                 # 主入口：串起数据获取 → 信号 → 回测 → 输出
├── requirements.txt        # 依赖清单
├── README.md               # 本说明文件
├── data/
│   └── data_fetcher.py     # 数据模块：akshare 获取个股/基准日频数据
├── strategy/
│   └── dual_ma.py          # 策略模块：双均线金叉/死叉信号
├── backtest/
│   └── engine.py           # 回测引擎：资金管理、手续费、滑点、净值计算
└── output/
    ├── results.py          # 输出模块：指标打印、净值曲线绘图
    └── nav_curve.png       # （运行后生成）归一化净值曲线图
```

## 策略规则

- **快线**：5 日简单移动平均；**慢线**：20 日简单移动平均（基于当日收盘价）。
- **金叉**（快线上穿慢线）→ 买入信号；**死叉**（快线下穿慢线）→ 卖出信号。
- 信号在 T 日收盘后产生，**T+1 开盘价执行**，避免未来函数。
- 回测采用全仓进出、按 100 股整手成交。

## 回测设定

| 参数   | 默认值                     |
| ---- | ----------------------- |
| 标的   | 平安银行（000001）            |
| 基准   | 沪深300（000300）           |
| 区间   | 2020-01-01 ~ 2024-12-31 |
| 初始资金 | 1,000,000 元             |
| 手续费  | 万分之三（双边）                |
| 滑点   | 千分之一（买价上浮 / 卖价下调）       |

## 安装与运行

### 1. 安装依赖

```bash
cd quant_backtest
pip install -r requirements.txt
```

> 建议使用 Python 3.9+（推荐 3.10 及以上）及虚拟环境。项目为纯 Python 实现，不依赖任何 C 扩展编译工具链。

```bash
python main.py

  vs 基准：累计超额 -32.95%，年化超额 -11.78%

样本外（2024-01-02 ~ 2024-12-31，242 个交易日）
  累计收益率  +10.12%  年化  +10.56%  最大回撤 -16.00%   夏普  0.50
  vs 基准：累计超额  -6.08%，年化超额  -6.37%
```

> 结果解读：
>
> 1. **样本内大幅跑输**：2020—2023 年平安银行处于下行 + 宽幅震荡行情，MA5/MA20 在震荡中  
>    频繁金叉死叉（27 次买入），叠加双边手续费与滑点持续磨损，趋势策略在无趋势行情中失效。
> 2. **样本外明显改善但仍跑输基准**：2024 年市场趋势性增强，策略转为正收益（+10.12%），  
>    但 924 行情的急涨以跳空方式展开，均线策略反应滞后，未能跑赢沪深300 的 +16.20%。
> 3. **差异来源**：信号滞后（均线天然滞后于拐点）、震荡磨损（交易成本）与择时失效是  
>    跑输基准的三个主因。这恰好说明**参数与标的的适配性**对趋势类策略至关重要，  
>    可修改 `main.py` 中的标的与均线窗口做进一步验证。

## 基准选择理由

选择**沪深300（000300）**&#x4F5C;为基准，理由：

1. **风格匹配**：标的是平安银行——A 股大盘蓝筹金融股，沪深300 恰好覆盖沪深两市市值最大、  
   流动性最好的 300 只股票，金融股权重高，风格与个股高度相关，是"同市场、同风格"的合理对照。
2. **市场代表性**：沪深300 是 A 股最常用的宽基业绩基准，机构组合普遍以其衡量超额收益，  
   结论易于解释与沟通。
3. **数据可得性**：akshare 免费提供其全部历史日频数据，与本项目数据链路一致。  
   若需要更严格的个股对照，可另行引入"买入持有平安银行"作为第二基准（把策略区间内的  
   `close` 序列首尾归一即为买入持有净值）。

## 关键实现说明

| 关注点    | 实现方式                                           |
| ------ | ---------------------------------------------- |
| 避免未来函数 | 信号基于 T 日收盘计算，`signal` 列 `shift(1)` 后在 T+1 开盘撮合 |
| 手续费    | 买入与卖出均按成交金额 × 万分之三扣减                           |
| 滑点     | 买入价 = 开盘价 ×(1+0.1%)，卖出价 = 开盘价 ×(1-0.1%)        |
| 整手约束   | 买入股数按 100 股向下取整，剩余资金留存为现金                      |
| 空仓处理   | 空仓期持股为 0，净值 = 现金 / 初始资金                        |
| 每日估值   | 收盘后总资产 = 现金 + 持股数 × 当日收盘价                      |
| 回撤计算   | 以历史净值最高点为基准，计算 `nav / cummax(nav) - 1` 的最小值    |
| 样本内外划分 | 2024-01-01 前为样本内、其后为样本外；信号全量计算后按日期切分，两段独立核算    |

## 常见问题

- **akshare 接口超时/限流**：akshare 数据来自公开网络接口，偶发超时属正常现象，稍后重试即可。
- **图中中文乱码**：Linux 系统需安装中文字体，例如 `sudo apt install fonts-noto-cjk`。
