# A股双均线策略量化回测项目

一个基于 **akshare + pandas + matplotlib** 的模块化 A 股日频量化回测项目，内置经典**双均线（金叉/死叉）策略**，严格避免未来函数（信号 T 日收盘产生，T+1 开盘执行），并计入手续费与滑点。

## 项目结构

```
quant_backtest/
├── main.py                 # 主入口：串起数据获取 → 信号 → 回测 → 输出
├── requirements.txt        # 依赖清单
├── README.md               # 本说明文件
├── data/
│   └── data_fetcher.py     # 数据模块：akshare 获取个股/基准日频数据
├── strategy/
│   └── dual_ma.py          # 策略模块：双均线金叉/死叉信号
├── backtest/
│   └── engine.py           # 回测引擎：资金管理、手续费、滑点、净值计算
└── output/
    ├── results.py          # 输出模块：指标打印、净值曲线绘图
    └── nav_curve.png       # （运行后生成）归一化净值曲线图
```

## 策略规则

- **快线**：5 日简单移动平均；**慢线**：20 日简单移动平均（基于当日收盘价）。
- **金叉**（快线上穿慢线）→ 买入信号；**死叉**（快线下穿慢线）→ 卖出信号。
- 信号在 T 日收盘后产生，**T+1 开盘价执行**，避免未来函数。
- 回测采用全仓进出、按 100 股整手成交。

## 回测设定

| 参数   | 默认值                     |
| ---- | ----------------------- |
| 标的   | 平安银行（000001）            |
| 基准   | 沪深300（000300）           |
| 区间   | 2020-01-01 ~ 2024-12-31 |
| 初始资金 | 1,000,000 元             |
| 手续费  | 万分之三（双边）                |
| 滑点   | 千分之一（买价上浮 / 卖价下调）       |

## 安装与运行

### 1. 安装依赖

```bash
cd quant_backtest
pip install -r requirements.txt
```

> 建议使用 Python 3.8+ 及虚拟环境。

### 2. 运行回测

```bash
python main.py
```

### 3. 查看结果

- **终端**：打印累计收益率、年化收益率、最大回撤、夏普比率等核心指标。
- **图片**：`output/nav_curve.png`，包含：
  - 策略归一化净值曲线（从 1.0 开始）
  - 沪深300 基准归一化净值曲线（从 1.0 开始）
  - 买入点（红色 ▲）与卖出点（绿色 ▼）标注
- **明细**：`output/trades.csv`，每笔买卖的日期、成交价、持股数量、现金与净值。

## 关键实现说明

| 关注点    | 实现方式                                           |
| ------ | ---------------------------------------------- |
| 避免未来函数 | 信号基于 T 日收盘计算，`signal` 列 `shift(1)` 后在 T+1 开盘撮合 |
| 手续费    | 买入与卖出均按成交金额 × 万分之三扣减                           |
| 滑点     | 买入价 = 开盘价 ×(1+0.1%)，卖出价 = 开盘价 ×(1-0.1%)        |
| 整手约束   | 买入股数按 100 股向下取整，剩余资金留存为现金                      |
| 空仓处理   | 空仓期持股为 0，净值 = 现金 / 初始资金                        |
| 每日估值   | 收盘后总资产 = 现金 + 持股数 × 当日收盘价                      |
| 回撤计算   | 以历史净值最高点为基准，计算 `nav / cummax(nav) - 1` 的最小值    |

## 常见问题

- **akshare 接口超时/限流**：akshare 数据来自公开网络接口，偶发超时属正常现象，稍后重试即可。
- **图中中文乱码**：Linux 系统需安装中文字体，例如 `sudo apt install fonts-noto-cjk`。
